AI processing and integrations

Manual categorisation, replaced by a measured AI service.

Product categorisation was a manual process. A language-model service now performs it, with the model selected on measured accuracy and cost.

3AI model families benchmarked
AWShosted and access-controlled
MFAwith full audit logging

The problem

Manual categorisation was slow and inconsistent, and the data required strict access control.

The system

A classification service hosted on AWS. Before a model was chosen, OpenAI, Anthropic and self-hosted open-weight models were benchmarked on accuracy against real categories and on cost per classification.

  • model selected on measured accuracy and cost
  • multi-factor authentication and full audit logging
  • a purpose-designed results database
  • integration with existing ticketing and reporting tools
  • continuous accuracy monitoring

The result

A manual workflow replaced by a secure service with measured accuracy and a known cost per item, integrated with existing tools.

  • AWS
  • Python
  • SQL
  • LLM APIs
  • REST APIs
  • Dashboards
